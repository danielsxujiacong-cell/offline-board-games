# 花见小路本地验收 · 2026-10-25

规则依据：[EmperorS4 官方游戏与规则下载页](https://en.emperors4.com/game/hanamikoji)，以及 [2016 EmperorS4 英文规则书](https://world-of-board-games.com.sg/docs/Hanamikoji.pdf)。网页使用原创美术与礼物名称，不改变七类数量或计分。玩家 1 由较年轻的一方担任。

## 逐项核验

| 项目 | 实现与验证 |
| --- | --- |
| 牌组与发牌 | 2/2/2/3/3/4/5，共 21 个唯一 ID；暗扣 1、双方各 6、牌库 8 |
| 摸牌 | 每个正式回合确认接手时摸一次；对方选牌、暗置牌查看、后台恢复均不摸牌 |
| 密约与取舍 | 分别暗置 1/2 张；密约只在结算时计分，取舍永不计分；本人可经独立确认查看 |
| 赠予与竞争 | 对方亲选 1/3 张或 1/2 组，余牌归行动方；竞争每组固定两张 |
| 行动限制 | 双方交替，四行动各一次；测试穷举双方全部 576 种行动顺序组合 |
| 结算 | 比较公开牌加密约；多者取得支持；有牌平局、零牌平局均保留原标记 |
| 胜负 | 至少 4 位或至少 11 分；冲突时 11 分优先；测试全部 2187 种支持分布 |
| 多轮 | 回收全部牌，含暗扣与取舍；保留支持、清空行动与私牌、交换先手 |
| 重开 | 取消保留对局；确认清除全部进度；实测胜利页重新开局 |
| 隐私 | 交接与后台移除私人牌 DOM；背景控件 inert；恢复与查看不改变原回合 |

## 实际执行

从项目根目录运行：

```powershell
python -m http.server 8080 --bind 127.0.0.1
node --test tests/hanamikoji.test.mjs
node tests/hanamikoji-browser.cjs
```

浏览器套件使用现有 Playwright 和 Edge；可用 `PLAYWRIGHT_PATH` 指向已安装的包，`TEST_URL` 指定 HTTP 地址。无需安装依赖。临时浏览器配置和截图放在项目 G 盘 `.openai/`，临时配置在测试结束后清理。

验收结果：20 项逻辑测试通过；浏览器实际触屏输入通过 320×568、375×667、390×844、568×320、667×375、844×390、768×1024、1280×900。无横向溢出，手机手牌至少 76px 宽，按钮至少 44px 高。完成真实多轮对局、继承与交换先手、获胜、取消/确认重开，以及暗置牌查看、后台恢复和交接测试。Network Offline 下大厅与所有当前游戏入口加载通过；运行时无页面异常。设备为浏览器模拟，未声称实体手机验证。

修复前实测：667×320 下确认按钮底边为 391px，超出屏幕且遮罩不能滚动；320px 下卡宽仅 60px，新游戏按钮仅 40px 高。已修复为可滚动遮罩、手机三列手牌和至少 48px 按钮。

本项目无构建工具或 build 脚本；HTML/CSS/JavaScript 就是静态部署产物。执行 app.js、engine.js、Service Worker 与浏览器测试脚本的 Node 语法检查，另由 HTTP 浏览器实际加载与离线检查验证静态资源。此轮只做本地验收，不提交、不推送。
