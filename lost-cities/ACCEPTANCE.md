# Lost Cities MVP 验收记录 · 2026-10-25

## 修复

1. 手机向右滑动后选择手牌，重绘会把横向滚动归零，所选牌离开视野。现在保留当前玩家手牌的滚动位置，交接仍移除私密 DOM。
2. 畸形存档的嵌套空值会抛出技术异常，部分不可能的历史分数可通过校验。现在检查嵌套数组、五色列、对局 ID、日期、投资数量与实际可组成的数字总和；统一显示导出备份/重置提示，不覆盖原始数据。存档格式仍为 v1，正常旧存档兼容。
3. 续局原先按上一局末手切换先手；现在遵循累计领先者先手。首局/清零让年长者担任玩家 1，累计同分玩家 1 先手是明确标注的网页约定；继续采用需求中的自由续局。
4. Just One 回归测试写死 v9 缓存，导致缓存更新后误报；测试改读当前 Service Worker 版本，不改该游戏源码。

## 逐项结果

| 检查 | 结果与证据 |
| --- | --- |
| 卡牌/初始化 | 五色各 3 投资、2–10 各 1，共 60 个唯一 ID；双方各 8、公共牌库 44 |
| 出牌 | 自动按同色入列，投资先于数字，最多 3 投资；数字严格递增；不合法操作拒绝且不改变状态 |
| 阶段与回合 | PLAY 先出牌/弃牌，DRAW 必须主动选择来源；不能重复操作；完成后恢复 8 张并交接 |
| 摸牌 | 仅弃牌堆顶可取；空堆禁用；刚弃牌不能立即拿回，刷新 DRAW 后限制保留；以后回合可取 |
| 结束 | 牌库剩 1 张时从弃牌堆摸牌不结束；抽走公共最后一张立即 END，不切下家，不再允许操作 |
| 计分 | 覆盖全部 10,240 个五色合法列组合；空列 0，纯投资 -40/-60/-80；7/8 张门槛、含投资、奖励不乘倍率；最高单列 156 |
| 实时/结算 | 共用计分函数；独立公式核对完整浏览器对局；特定 8 张路线得 68，另一方 -40；平局显示正确 |
| 累计/历史 | 三局非零分数累计，唯一对局 ID；中断结算后恢复；反复刷新 END 不重复累计 |
| 续局/清零 | 续局重新 8/8/44 并保留历史，累计领先者先手；取消清零不改变数据，确认才重置 |
| 刷新 | PLAY 的所选牌、DRAW 的完整牌组顺序和弃牌限制恢复，刷新后先确认身份 |
| 异常存档 | 损坏 JSON、版本不兼容、嵌套空值、重复卡牌和不可能历史数据均拒绝；原始存档保留，可导出；存储额度不足显示警告且不覆盖旧数据 |
| 手机 | Edge 浏览器触屏模拟 375px/390px：真实触摸事件横滑、最右侧手牌保持可见、按钮实际点击、关键按钮至少 44px，无页面横向溢出 |
| 隐私 | 交接/手动隐藏/刷新/离开再返回时无手牌或私密操作 DOM，确认后才显示当前玩家 8 张；从不显示对手手牌 |
| 离线 | HTTP 下注册 SW，Network Offline 遍历大厅与所有 14 款游戏入口，并检查由 SW 返回，防止大厅兜底造成假通过 |
| 回归 | 花见小路、Jaipur、Just One、损友审判庭、嘴炮炸弹、演技三部曲现有浏览器套件复跑通过 |

## 可复现命令

在仓库根目录启动 HTTP 服务：`python -m http.server 8080 --bind 127.0.0.1`。

- `node --test tests/*.test.mjs`
- `node tests/lost-cities-browser.cjs`：完整 44 回合、恢复/结算/确认/离线入口
- `node tests/lost-cities-audit-browser.cjs`：375/390 触摸、受控边界牌局、68/-40 结算、平局、存储异常
- `node --check lost-cities/app.js`、`node --check lost-cities/engine.js`、`node --check lost-cities/storage.js`、`node --check service-worker.js`

浏览器测试复用已有 Playwright 与 Edge，可设 `PLAYWRIGHT_PATH`（旧游戏脚本用 `NODE_PATH`）和 `TEST_URL`；新测试会等待当前 SW 更新，防止旧缓存掩盖修改。无需安装游戏依赖。

本项目是纯 HTML/CSS/JavaScript，没有构建脚本；源码即静态发布产物。使用语法检查、HTTP 实际加载和离线资源验收验证产物。截图在 G 盘 `.openai/lost-cities-375-audit.png` 和 `lost-cities-390-audit.png`。手机结果为浏览器触屏模拟，不声称已使用实体手机或两位真人主观试玩。

原版核对依据：[KOSMOS 1999 原版规则书（图书馆存档）](https://content.cmpl.org/bg/LostCities.pdf)，重点核对卡牌组成、出后摸、投资/数字顺序、取弃牌限制、最后一张立即结束、投资倍率、八张奖励及累计领先者先手。自由续局与累计同分先手按上述 MVP 约定。
