# 张楠问答

入口：<https://games.danielxu.cn/zhangnan/>。本仓库直接维护，原生 HTML/CSS/JavaScript，无安装、构建、API Key 或后端；沿用 GitHub `main` → 既有 EdgeOne 静态发布，不增加托管项目或修改 DNS。

## 文件与维护

- `index.html` / `style.css`：奶油白、淡紫色小舞台及手机布局，输入区跟随 VisualViewport 和安全区域。
- `data.js`：经典问答、同义问法、五批快捷问题和短点击反馈。香蕉、早起、114514 与身份梗为用户确认的例子；其余为按此风格创作的短句。
- `engine.js`：独立回复引擎，`ZhangnanEngine.createReplyEngine({ history, recent, random }).answer(question)` 返回 `{ answer, category }`；`history` 可选，接收已有 `{ question, answer, category?, time? }` 记录。`recent` 与测试用 `random` 继续兼容，经典句和数字梗不受去重影响。
- `app.js`：串行提问队列（最多另排 5 个）、逐字回答、历史、重开、输入法保护和离线注册。重开用会话编号取消旧异步流程；动画没有按提问增加 interval。
- `assets/character.webp`：用户定稿的紫灰短发、深色日系学院穿搭 Q 版角色。
- `assets/blink.webp` / `assets/talk.webp`：生成的闭眼及开口表情。CSS 羽化蒙版只取眼睛／嘴部，头和身体使用独立裁剪层；待机眨眼与呼吸、思考歪头、回答嘴型、点击反馈均真实实现。换素材需同时校准 `style.css` 的蒙版坐标和 HTML 中的头／身体 clipPath。不要只换一张图并宣称完成动画。

回复是**纯前端规则与句式生成**，按常见问法、单位和有限上下文接话，没有接入大模型。以后接 AI 时保留引擎接口，将联网请求单独实现，不将 API 或私密请求加入 Service Worker 缓存。

## 短句、固定梗和上下文

回答通常 4～12 个字符，最多 20 个字符、一个完整句子。先选择能完整说完的短句；对象或动作过长时使用完整短兜底，不截断成半句话。经典句每次稳定返回：

- 怎么才能早起／如何才能早起 → 早起就能早起。
- 香蕉什么味／这根香蕉是什么味道 → 就是香蕉味。
- 你是谁／你哪位／你到底是谁 → 我是你爹。此梗只匹配直接身份提问；询问名字回答“张楠。”，日常仍是平淡短废话。
- 我好累 → 累了就是累了。你在敷衍我吗 → 我在回答你。

明确询问数值时使用 `114514`。优先采用“多少／几”后明确给出的单位，避免从“买 3 瓶牛奶多少钱”中的“瓶”误取单位。默认：金额元、年龄岁、身高厘米、长度米、体重斤、面积平方米、温度度、时长分钟、数量个、时刻点；尺寸等无法判断单位时只报数字。原因和判断先按问法分流：“为什么贵”回答“因为不便宜。”，“贵不贵”回答“贵就是贵。”，仅提到数字的陈述不会因此触发数字梗。“绳子多长”与“多长时间”分别走长度和时长。

引擎保留当前话题及最近三轮问答，初始化只重放最近三轮有效记录。“牛奶多少钱 → 那面包呢”继承价格和单位；“为什么这么贵”保留价格话题；“你刚才说什么／再说一遍”复述上一条回答。味道和方法也支持短省略追问。明确的新问题优先，并替换原话题；接不住的新话题清空旧话题后使用短兜底。`.reset()` 同时清空话题与记录。旧版超过 20 字的回答仍可显示在历史中，要求复述时用完整短句说明“刚才那句说过了。”。

## 记录与隐私

已完成问答存入当前浏览器的 `localStorage['zhangnan-chat-v1']`（版本 1），最多保留最近 100 组；刷新恢复最后一组和最近三轮可推断的话题，历史面板可查看。沿用原格式，无存档迁移。排队和未完成问题仅存内存，刷新取消。无账号、上传或跨设备同步。存储不可用时仍可玩；“重新聊聊”经确认后清空该设备的问答记录和上下文并取消队列。所有输入通过 `textContent` 显示。

发布素材均为生成的卡通衍生图；私人参考照片未复制进仓库。WebP 仅做发布编码压缩，原始生成文件留在云端工作区。截图、日志和临时浏览器配置在被忽略的 `.openai/zhangnan/`，不提交。

## 本地预览与验证

从仓库根目录启动：

```sh
python -m http.server 8080
node --test tests/zhangnan.test.mjs
node tests/zhangnan-browser.cjs
```

浏览器测试复用现有 Playwright（可设 `PLAYWRIGHT_PATH`）、Linux 系统 Chromium / Windows Edge；`TEST_BROWSER_PATH` 指定可执行文件，`TEST_URL` 指定 HTTP 根地址，`TEST_OUTPUT_DIR` 可指定截图目录。覆盖真实发送、快捷问题、三条连续排队、IME、固定梗／数字单位／原因与判断、话题继承与切换、历史刷新恢复与清空、重开与取消旧回答、实际表情层和恒定动画数量、长问题、文本注入、320/390/768/1440px、横屏、模拟键盘、减少动态效果，以及 HTTP Service Worker 下大厅和全部实际游戏入口的 Network Offline 导航与断网追问。

代码更新后递增根 `service-worker.js` 的 `CACHE_NAME`，保留其他游戏的资源列表和逻辑。新增文件同步加入预缓存；入口维护在根 `index.html`，SEO 地址在 `sitemap.xml`。**不运行 `sync-games.ps1`。**

自动化设备模拟不等于实体 iPhone / Android 键盘与触屏验收；请在实际手机打开正式地址检查手感。
