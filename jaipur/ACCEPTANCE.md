# 斋浦尔验收与维护（2026-10-25）

规则依据：[Space Cowboys 原版规则书](https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/11/Rules-JAIPUR-12x17-Version-EN_BD.pdf)。上一需求指定的全部牌张、商品筹码和奖励池数值保持不变。官方同分顺序是总分、奖励筹码数量、商品筹码数量；仍完全相同时继续沿用页面明确标注的网页自定义规则「本轮先手获胜」，并非官方规则。

## 已修复

- 568×320 横屏下，原交接面板高 398px，确认按钮底部约 359px，落在屏幕之外。改为可滚动的原生模态对话框，横屏紧凑布局；确认按钮可直接触控。
- 原交易方式按钮高 38px、规则按钮高 28px。所有按钮最小 44×44 CSS 像素，保留卡牌布局与印度集市画风。
- 原遮罩只有 ARIA 标记，未阻止背景键盘焦点。现使用 `showModal()`，禁用 Escape 关闭并兼容不支持 `closedby` 的浏览器，避免交接被误关后卡住。
- 返回浏览器历史或页面进入后台时重新隐藏手牌，确认同一位玩家后恢复原手牌，不抽牌、不消耗回合。刷新仍按页面说明重新开局。
- 原索引校验会跳过 JavaScript 稀疏数组的空洞。现逐个校验所有位置，阻止异常索引制造不存在的牌、伪造贵重品出售张数或额外领取筹码。正常界面无法构造这种数组，但引擎边界仍须拒绝。

## 可重复验收

无依赖安装、无框架构建步骤。HTTP 服务在仓库根目录启动，复用已有 Playwright 与 Edge：

```powershell
python -m http.server 8080
node --test tests/jaipur.test.mjs tests/jaipur-audit.test.mjs
node --check jaipur/engine.js
node --check jaipur/app.js
node tests/jaipur-audit-browser.cjs
node tests/jaipur-browser.cjs
```

`PLAYWRIGHT_PATH` 可指定已有 Playwright，`TEST_URL` 可改为正式域名。浏览器配置和截图均在 G 盘项目忽略目录 `.openai/`；每次测试创建独立配置，退出后清理，防止旧 Service Worker 或 HTTP 缓存把旧代码当作新代码验收。

- 规则测试覆盖 55 张牌、发牌与骆驼分离、7 张上限、三种进货、2～5 张交换、同色冲突、贵重品门槛、部分出售、奖励空池、筹码耗尽、补牌失败/刚好补满、骆驼同数、全部计分与同分、徽章、输家先手、整场结束和新轮重置。
- 增加 80 个固定种子的完整比赛；独立生成合法交换与部分出售候选，并逐步验证每种牌数量、手牌上限、商品收入、奖励数量与轮末分数。
- 触控验收覆盖 320×568、360×640、390×844、430×932、568×320、667×375、844×390、932×430。满手 7 张、市场 5 张逐项滚动、命中测试，检查按钮大小、遮挡、横向溢出、双击、原生模态焦点、取消重开、规则窗口与历史返回隐私。
- 完整浏览器比赛通过实际触控操作，过程中反复切换竖屏和横屏；用独立商品筹码账本及有限奖励池组合核算每轮收入，再检查骆驼分、同分规则、徽章与最终赢家，非仅检查胜利文案。
- 发布后对正式域名再运行两份浏览器脚本，确认子路径刷新、首页入口、整场操作、无页面异常，以及 Network Offline 下大厅和全部游戏入口。

仅做浏览器手机与触控模拟，不冒充实体手机人工试玩。
